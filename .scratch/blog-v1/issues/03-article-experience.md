# 03: 文章页体验

**What to build:** 完整的文章阅读体验：目录、代码高亮、阅读时长、作者与日期、上一篇/下一篇、文章页脚（CC BY 4.0、相关文章）。正文与目录在无 JavaScript 时仍可用。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 文章页展示标题、描述、发布日期、更新日期（如有）、作者、标签、专题（如有）、阅读时长。
- [ ] 目录列出 h2/h3 标题，锚点链接可用。
- [ ] 代码块有语法高亮，文本可复制。
- [ ] 上一篇/下一篇按文章顺序链接。
- [ ] 页脚展示 CC BY 4.0 与相关文章。
- [ ] 禁用 JavaScript 后目录链接与正文仍可用。
- [ ] Playwright 在构建产物上断言以上行为。
