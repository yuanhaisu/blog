# 04: 分类与归档

**What to build:** 标签页、专题页与归档页，以及文章页上的标签/专题入口。读者可以按主题浏览，按顺序阅读「一人交付实验」，按时间浏览全部文章。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 标签页列出该标签下所有已发布文章，按日期倒序。
- [ ] 专题页按 `order` 排序文章，并展示专题说明（如有）。
- [ ] 归档页按年/月分组列出全部已发布文章。
- [ ] 文章页链接到它所属的标签与专题。
- [ ] 草稿不出现在任何分类或归档页。
- [ ] 未知标签/专题返回 404。
- [ ] Playwright 覆盖标签页、专题页、归档页。
