# ADR-0002: 托管地域与合规（ICP 备案，v1 已被 ADR-0007 取代）

- 状态：**v1 已取代**；保留为未来国内镜像的选项
- 日期：2026-11-03
- 决策者：用户 + Claude

> 2026-11-04 更新：v1 改为 GitHub 内容源 + Cloudflare Pages 托管，不执行本 ADR 的阿里云 + ICP 方案。若未来做国内镜像，再回到本 ADR 的备案路径。

## 背景

- 博客主要受众在国内，国内 AI 生态对国内服务器抓取更友好。
- 用户明确表示愿意进行 ICP 备案并使用国内云。
- 用户同时希望被国外 AI 生态发现，存在「国内托管 vs 国外抓取」的张力。

## 决策

- 使用**中国大陆境内云服务器**（阿里云 / 腾讯云轻量应用服务器，厂商与配置待定）。
- 为 `yuanhaisu.com` 完成 **ICP 备案**；网站上线后按当地要求完成**公安联网备案**（通常 30 日内）。

## 后果

### 收益

- 国内访问速度与稳定性最佳。
- 百度、豆包、元宝等国内 AI 抓取链路最短。
- 可接入国内 CDN、对象存储、统计与评论服务。

### 代价与约束

- 备案周期通常 **1–3 周**，期间该域名不能对外提供网站服务，需要提前规划上线时间。
- 备案要求域名实名认证主体与备案主体一致；服务器必须是备案厂商的产品；网站名称与内容需符合个人备案规范，**不得涉及经营性内容**。
- 内容接受国内监管，敏感话题不可写——对「跨领域混合」写作是实质约束。
- 国外 AI 爬虫仍可访问境内站点，但跨境延迟较高；需要通过静态化、CDN、合理的缓存策略降低抓取成本。

## 待决问题

- `yuanhaisu.com` 当前注册商是否在工信部批复名单内？是否需要转入国内注册商？
- 具体云厂商、地域与配置。
- 是否需要境外镜像或 CDN 回源方案以服务国外 agent。
- 备案主体与网站名称的最终确定。
